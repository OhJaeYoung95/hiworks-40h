샘플에서 시작하기 (선택)

상황별 그림

칸에 그림을 끌어다 놓거나 그림 고르기를 누르세요. 여러 장을 넣으면 차례로 넘어가며 움직여요. 서 있을 때 한 칸만 채워도 돼요. 빈 칸은 비슷한 그림으로 대신 나와요.

다른 상황도 그림 넣기

특별 동작 (선택)

쉬는 동안 가끔 하는 이 캐릭터만의 동작이에요. 예: 커피 마시기, 춤추기

말풍선

비워 두면 기본 말이 나와요.

미리 보기

"서 있을 때" 그림을 넣으면 여기서 움직여요.

코드 만들기

코드를 복사해 메신저로 보내세요. 길면 파일로 저장해서 파일을 보내도 돼요.

테마 만들기에 넣기를 누르면 이 캐릭터가 테마 만들기의 캐릭터 목록에 들어가요. 거기서 테마를 만들고 테마 코드를 하이웍스 패널 🎨 → ＋ 테마 코드 넣기에 넣으면 화면에 나와요. 캐릭터 코드를 받은 사람도 테마 만들기의 캐릭터 코드 넣기에 넣어 쓰면 돼요. 같은 캐릭터를 고쳐서 다시 보내면 받은 사람 화면에서도 새 그림으로 바뀌어요.
