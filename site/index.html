하이웍스 40시간 퇴근 계산기

근무 페이지에 금요일 퇴근 가능 시각을 띄우고, 작은 캐릭터들이 화면 아래를 돌아다니는 도구예요. 한 번 설치하면 업데이트는 자동으로 받아요.

설치하기

  1. Tampermonkey 설치 Chrome 웹 스토어에서 Tampermonkey를 설치합니다. 무료예요.
  2. 사용자 스크립트 허용 켜기 주소창에 chrome://extensions를 입력하고, Tampermonkey의 세부정보에서 사용자 스크립트 허용을 켭니다. 이 항목이 없다면 오른쪽 위 개발자 모드를 켜 주세요.
  3. 스크립트 설치 아래 버튼을 누르면 Tampermonkey 설치 화면이 뜹니다. 설치를 누르세요.
    스크립트 설치 (v{{VERSION}})
  4. 근무 페이지 새로고침 하이웍스 근무 페이지를 F5로 새로고침하면 오른쪽 아래에 패널이 나타나요.

계산 규칙

  • 주 {{WEEKLY_HOURS}}시간을 채워야 해요.
  • 근무는 {{WORK_START}}부터 세요. 그보다 일찍 출근해도 {{WORK_START}} 전 시간은 넣지 않아요.
  • 점심시간 {{LUNCH}}은 근무시간에서 빠져요.
  • 금요일에 {{WEEKLY_HOURS}}시간을 일찍 채우면 {{FRIDAY_LEAVE}}에 퇴근할 수 있고, 못 채웠으면 채우는 시각까지 근무해요.
  • 주간 합계의 휴가 시간도 {{WEEKLY_HOURS}}시간에 포함해요.
  • 월~목에는 목요일까지 하루 8시간씩 일한다고 보고 금요일 예상 퇴근 시각을 보여 줘요.

사용법

  • 패널의 – 버튼으로 패널을 접을 수 있어요.
  • 패널의 🐾 버튼으로 캐릭터를 끄고 켤 수 있어요. 설정은 각자 저장돼요.
  • 캐릭터들은 종이에서 빠져나와 돌아다녀요. 캐릭터를 누르면 동그란 버튼이 나와요: 남은 시간, 점프, 쓰다듬기, 간식, 특기, 📄 가두기.
  • 가두기를 누르면 캐릭터가 종이에 붙어 왼쪽 벽으로 날아가요. 벽의 종이를 누르면 다시 풀려나요.
  • 캐릭터를 끌어 올렸다 놓으면 떨어져요.
  • 패널의 👋 버튼으로 동료들과 방장의 방에 모일 수 있어요 (최대 8명). 방장이 방 만들기를 하고, 들어올 사람마다 초대 코드를 보내 답장 코드를 돌려받으면 들어와요.
  • 방에 있는 동안 모두의 화면에 방장의 테마 캐릭터들이 돌아다니고, 그 위로 각자 고른 아바타가 이름표를 달고 나와요. 적은 말은 아바타 말풍선과 왼쪽 벽 채팅 목록에 떠요. 가둔 캐릭터의 종이는 채팅 목록 위에 붙어요.
  • 방장이 사람 이름을 누르면 ✏️ 꾸미기 권한을 줄 수 있어요. 권한을 받은 사람은 자기 캐릭터를 방에 데려오거나 방 캐릭터를 뺄 수 있어요.
  • 방에서 나가기를 누르면 내 아바타가 종이에 붙어 다른 사람 화면의 왼쪽 벽으로 날아갔다가 잠시 뒤 사라지고, 내 화면은 내 테마로 돌아와요. 서버 없이 방장 브라우저가 말을 전해 주므로, 방장이 나가거나 새로고침하면 방이 닫혀요. 대화는 어디에도 저장되지 않아요.
  • 패널의 🎨 버튼으로 캐릭터 테마를 고르고, 동료에게 받은 테마 코드를 넣을 수 있어요.

내 캐릭터 만들기

캐릭터 만들기 페이지에서 그림을 끌어다 놓으면 나만의 캐릭터가 돼요. GitHub 가입은 필요 없어요.

  1. 서 있을 때 칸에 그림을 넣어요. 걷기·축하 같은 다른 칸은 넣고 싶을 때만 넣어요.
  2. 캐릭터 코드 만들기를 누르고 코드 복사(길면 파일로 저장)를 눌러요.
  3. 테마 만들기에 넣기를 누르고, 테마 만들기에서 그 캐릭터를 넣어 테마를 만들어요. 받은 캐릭터 코드도 테마 만들기의 캐릭터 코드 넣기에 넣으면 돼요.
  4. 테마 코드를 복사해 하이웍스 패널 🎨 → ＋ 테마 코드 넣기에 붙여 넣으면 화면에 나와요. 테마 코드에는 캐릭터 그림도 함께 들어 있어서, 동료에게 보내면 동료 화면에도 그대로 나와요.

캐릭터는 각자 브라우저에만 저장되고 어디로도 올라가지 않아요. 직접 그렸거나 써도 되는 그림만 넣어 주세요.

다른 근무 페이지에서 쓰기

하이웍스가 아니어도, 근무시간이 화면에 글자로 나오는 웹 근무 페이지라면 쓸 수 있어요. 근무시간을 사람이 조절하는 유연근무제(주·월 단위 선택근무, 시차출퇴근)에 맞춰져 있어요.

  1. 근무 페이지를 열고 Tampermonkey 아이콘 → ⏱ 이 사이트에서 40시간 계산기 켜기를 눌러요.
  2. 패널의 ⚙️ 회사 설정에서 근무 방식(주 단위 / 월 단위 / 하루 단위)과 목표 시간, 근무 인정 시작, 점심시간을 맞춰요.
  3. 읽을 곳 가르치기를 누르고, 안내에 따라 화면에서 누적 근무시간 → 출근 시각 → 퇴근 시각 → 휴가 칸을 차례로 눌러요. 없는 칸은 건너뛰면 돼요.
  4. 패널에 계산이 나오면 끝이에요. 설정 코드 복사로 같은 근무 페이지를 쓰는 동료에게 보내면, 동료는 설정 코드 넣기만 하면 돼요.

하이웍스에서도 ⚙️로 규칙(목표 시간, 근무 인정 시작 등)을 바꿀 수 있어요. 근무 페이지 화면이 크게 바뀌어 못 읽게 되면 읽을 곳을 다시 가르쳐 주세요.

먼저 연습해 보고 싶다면 연습용 근무 페이지에서 똑같이 해 보세요. 다 해 본 뒤에는 Tampermonkey 메뉴의 "끄기"로 꺼 두세요. 이 안내 페이지와 같은 주소라서, 켜 두면 여기에도 패널이 떠요.

업데이트

Tampermonkey가 하루에 한 번쯤 새 버전을 확인해서 자동으로 받아요. 바로 받고 싶으면 Tampermonkey 아이콘 → 대시보드에서 스크립트를 고르고 업데이트 확인을 누르세요.

안전한가요?

  • 근무 페이지의 화면 글자를 읽어 계산만 하고, 어떤 데이터도 외부로 보내지 않아요.
  • 하이웍스 근무 페이지와, 직접 켜기로 등록한 사이트에서만 동작해요. 다른 사이트에서는 Tampermonkey 메뉴만 만들고 아무것도 하지 않아요. (설치할 때 "모든 사이트" 권한이 보이는 건 어느 근무 페이지든 등록할 수 있게 하기 위해서예요.)
  • 코드는 GitHub 저장소에 공개되어 있어요.

문제 해결

패널이 안 보여요
근무 페이지를 새로고침하고, Tampermonkey의 사용자 스크립트 허용이 켜져 있는지 확인하세요.
패널이나 캐릭터가 두 개씩 나와요
예전에 폴더로 설치한 확장 프로그램이 남아 있어요. chrome://extensions에서 삭제하세요.
"화면에서 읽지 못함"이라고 나와요
하이웍스 화면이 바뀌어 글자를 못 읽은 경우예요. 패널의 "누락" 항목을 관리자에게 알려 주세요.

하이웍스와 관계없는 개인이 만든 비공식 도구예요. 계산 결과는 참고용이니, 정확한 근무시간은 하이웍스 기록을 기준으로 해 주세요.
