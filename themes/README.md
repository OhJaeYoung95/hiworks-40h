# 캐릭터 테마

테마는 **어떤 캐릭터를, 어떤 이름과 크기로, 몇 명** 내보낼지 정한 묶음입니다.
그림은 담지 않고 캐릭터 id만 가리키므로 공유 코드가 짧습니다. 그림은 기본 캐릭터나 [캐릭터 팩](../characters/README.md)에서 옵니다.

하이웍스 패널의 🎨 버튼을 누르면 테마 목록이 나오고, 누르면 바로 바뀝니다. 고른 테마는 그 브라우저에 기억됩니다.

| 목록 | 어디서 오나 | 누구에게 보이나 |
|---|---|---|
| 기본 | 지금 배포된 캐릭터 그대로 | 모두 |
| 공용 | 이 폴더의 `themes/<id>.json` | 모두 (파일을 더하면 목록이 늘어납니다) |
| 내 테마 | 🎨 → **＋ 코드로 추가**에 붙여 넣은 공유 코드 | 그 브라우저만 |

## 만들기

1. **테마 만들기** 화면을 엽니다: https://ohjaeyoung95.github.io/hiworks-40h/themes.html (패널 🎨 → 테마 만들기 ↗)
2. 캐릭터를 넣고, 이름과 크기를 정합니다. 같은 캐릭터를 여러 번 넣어도 됩니다. 화면 아래에서 실제처럼 움직입니다.
3. 나누는 방법은 둘입니다.
   - **공유 코드:** `HW40T1.`로 시작하는 코드를 복사해 동료에게 보냅니다. 받은 사람은 🎨 → **＋ 코드로 추가**.
   - **공용 테마:** 화면의 JSON을 이 폴더에 `<id>.json`으로 저장해 푸시하면 모두의 목록에 나옵니다.

## 파일 형식

```json
{
  "name": "조용한 사무실",
  "cast": [
    { "id": "hodu" },
    { "id": "mong", "name": "몽몽이", "size": 72 },
    "kong"
  ]
}
```

| 항목 | 설명 |
|---|---|
| `name` | 목록에 나오는 테마 이름 (20자까지) |
| `cast` | 나올 캐릭터 목록, 10명까지. 문자열 id만 써도 됩니다 |
| `cast[].id` | 기본 캐릭터(`kong`, `ppyong`, `hodu`, `mong`, `bora`) 또는 캐릭터 팩 id |
| `cast[].name` | 이 테마에서 부를 이름 (12자까지). 마우스를 올리면 보입니다 |
| `cast[].size` | 크기(px), 32~160. 없으면 캐릭터 기본 크기 |

- 파일 이름(확장자 뺀 부분)이 테마 id입니다. 영문 소문자·숫자·`-`만 씁니다. `_`로 시작하면 배포에 넣지 않습니다.
- 없는 캐릭터를 가리키면 빌드가 멈추고 GitHub Actions에 이유가 나옵니다.
- 공유 코드에 이 버전에 없는 캐릭터가 있으면 그 캐릭터만 빼고 추가하고, 무엇을 뺐는지 알려줍니다.
